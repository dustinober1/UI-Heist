# Installation Guide

## Prerequisites

- [Google Chrome](https://www.google.com/chrome/) browser.
- [Git](https://git-scm.com/) (optional, for cloning the repository).

## Steps

1. **Get the Code**
   - Clone the repository:
     ```bash
     git clone https://github.com/your-username/ui-heist.git
     ```
   - Or download the ZIP file and extract it.

2. **Open Chrome Extensions Page**
   - Open Chrome and navigate to `chrome://extensions`.
   - Alternatively, click the three-dot menu > **Extensions** > **Manage Extensions**.

3. **Enable Developer Mode**
   - In the top right corner of the Extensions page, toggle the **Developer mode** switch to ON.

   ![Developer Mode Switch](placeholder-image-url)

4. **Load Unpacked Extension**
   - Click the **Load unpacked** button that appears in the top left.
   - Navigate to the directory where you downloaded/cloned the code.
   - Select the `ui-heist` folder (the folder containing `manifest.json`).

   ![Load Unpacked Button](placeholder-image-url)

5. **Verify Installation**
   - You should now see the "UI Heist" card in your extensions list.
   - The UI Heist icon should appear in your browser toolbar (you might need to pin it).

   ![Extension Card](placeholder-image-url)
