# UI Heist

UI Heist is a Chrome Extension that allows you to inspect any website, capture UI elements, and instantly convert them into React components with inline styles.

## Features

- **Visual Inspection:** Highlight elements on any webpage.
- **Deep Capture:** Recursively captures the selected element and all its children.
- **Smart Conversion:** Converts computed styles into clean React inline styles.
- **Instant Export:** Generates ready-to-use React Functional Components.

## Quick Start

1. Install the extension (see [Installation](docs/INSTALLATION.md)).
2. Click the extension icon and hit **Start Inspecting**.
3. Click an element on the page.
4. Re-open the extension popup to copy your React code!
